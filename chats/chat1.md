I've built **Onde Haptic Wellness** as one canvas page. It shows all 28 screens as iPhone 16 Pro frames (393×852), grouped by flow, and every frame is clickable. The first frame starts at the splash and runs the whole app. It's with an automatic reviewer now, so I haven't checked the screenshots myself yet.

- **Main flow:** Home → mood card → Start Experience takes 2 taps. Stop is the largest button on the session screen, and double-tapping anywhere also stops.
- **Vibration:** the phone really vibrates on Android. iPhones don't let a web page use the vibration motor, so on iPhone you only see the visual feedback.
- **What works:** sliders drag, sessions count down, and you can pause and resume. Segments on the timeline can be dragged or moved with arrow buttons. You can add segments from a panel that slides up, and saving adds the pattern to your list. Privacy and settings switches work, the paywall lets you pick a plan, and account deletion only goes through after you type DELETE.
- **Premium and Reduce Motion:** these switches in the design's settings panel change all frames at once. Reduce Motion is also inside the app, under Settings → Accessibility.
- **Stand-ins:** "Onde" is a placeholder name I picked. The font is Plus Jakarta Sans, which is close to Inter.

**Not done yet:** a sheet showing each reusable component on its own (they already exist inside the screens), the five store screenshots, and the final app icon file.
